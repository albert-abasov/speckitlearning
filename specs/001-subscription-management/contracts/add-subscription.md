# API Contract: Add Subscription

**Endpoint**: `POST /api/v1/subscriptions`

**Version**: v1 (stable for MVP)

**Date**: 2026-07-31

**Status**: Ready for implementation

---

## Summary

Adds a new RSS/Atom feed subscription to the user's collection. The server stores the URL in-memory and returns the created subscription with a unique identifier and timestamp.

---

## Request

### HTTP Method & Path

```
POST /api/v1/subscriptions
```

### Headers

| Header | Value | Required | Notes |
|--------|-------|----------|-------|
| `Content-Type` | `application/json` | Yes | Indicates JSON request body |
| `Accept` | `application/json` | Yes | Indicates JSON response expected |

### Request Body (JSON)

**Content-Type**: `application/json`

**Schema**:
```json
{
  "url": "string (non-empty, whitespace trimmed)"
}
```

**Example Request**:
```json
{
  "url": "https://devblogs.microsoft.com/dotnet/feed/"
}
```

**Field Details**:

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| `url` | string | Yes | Non-empty after trim; max 2048 chars (future) | Feed URL as provided by user; stored as-is, no validation or format checking in MVP |

### Validation Rules (Request Level)

1. **URL field must be present**: If missing, return 400
2. **URL must not be empty**: If null, empty string, or whitespace-only, return 400
3. **URL must be trimmed**: Leading/trailing whitespace removed before validation
4. **No format validation**: Any non-empty string accepted (future Extended-MVP adds URL format checking)

### Examples

**Valid Request** (standard feed URL):
```json
{
  "url": "https://example.com/feed.xml"
}
```

**Valid Request** (with whitespace, trimmed before processing):
```json
{
  "url": "  https://example.com/feed.xml  "
}
```

**Invalid Request** (empty string):
```json
{
  "url": ""
}
```
→ Returns 400 Bad Request

**Invalid Request** (missing field):
```json
{}
```
→ Returns 400 Bad Request

## Success Response

### HTTP Status Code

```
200 OK
```

### Response Headers

| Header | Value |
|--------|-------|
| `Content-Type` | `application/json` |

### Response Body (JSON)

**Schema**:
```json
{
  "id": "string (UUID)",
  "url": "string",
  "addedAt": "string (ISO 8601 UTC datetime)"
}
```

**Example Response**:
```json
{
  "id": "a1b2c3d4-e5f6-47a8-b9c0-d1e2f3a4b5c6",
  "url": "https://devblogs.microsoft.com/dotnet/feed/",
  "addedAt": "2026-07-31T16:17:16.123Z"
}
```

**Field Details**:

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (UUID) | Unique identifier generated by server; globally unique within session |
| `url` | string | Feed URL as provided by user (trimmed, no further transformation) |
| `addedAt` | string (ISO 8601 UTC) | Timestamp when subscription was created; always UTC; format: `YYYY-MM-DDTHH:mm:ss.fffZ` |

## State Changes

### Server Side

- **Subscription created**: New `Subscription` object created with unique ID and current UTC timestamp
- **Added to collection**: Subscription added to in-memory `List<Subscription>`
- **Stored for session**: Subscription persists for the duration of the user's session (until app restart)
- **Data loss on restart**: If application restarts, all subscriptions (including this new one) are lost

### Client Side (Blazor Frontend)

- **List updated**: Subscription list component receives response and adds new subscription to displayed list
- **Input field cleared**: Text input field is cleared, ready for next entry
- **Visual feedback**: (Optional) Toast/notification shows "Subscription added" confirmation
- **No page refresh required**: Update happens asynchronously; user remains on the same page

---

## Idempotency

**Idempotent**: NO

- Multiple identical POST requests will create multiple subscriptions with identical URLs but different IDs
- This is accepted behavior for MVP (per spec, duplicates are allowed)
- Future Extended-MVP may add duplicate detection and return existing subscription instead

### Example

Request 1:
```json
{ "url": "https://example.com/feed" }
```

Response 1:
```json
{ "id": "id-1", "url": "https://example.com/feed", "addedAt": "2026-07-31T16:17:16Z" }
```

Request 2 (identical to Request 1):
```json
{ "url": "https://example.com/feed" }
```

Response 2 (different ID, same URL):
```json
{ "id": "id-2", "url": "https://example.com/feed", "addedAt": "2026-07-31T16:17:30Z" }
```

**Result**: Two subscriptions in list with identical URLs but different IDs and timestamps.

## Security Considerations

### URL Input Security (MVP)

- **No URL format validation**: Any non-empty string accepted
- **No URL fetching**: URL is stored; no HTTP request made to fetch or validate URL
- **No shell execution**: URL is never passed to shell command or system execution
- **Storage**: URL stored as-is in memory; no transformation or encoding

### Future Security (Extended-MVP)

- **URL format validation**: Validate URI scheme (http/https), domain, path structure
- **URL allowlisting**: Restrict to known domains or whitelist user-provided domains
- **Feed fetching**: When Extended-MVP adds feed fetching, validate URL and handle network errors
- **Content sanitization**: When Extended-MVP displays feed content, sanitize HTML/scripts

### No Authentication (MVP)

- **Single user**: MVP assumes single user; no authentication required
- **No secrets**: API requires no credentials; localhost access only
- **Future auth** (Extended-MVP): Add JWT or API key authentication if multi-user support added

## Implementation Notes

### ASP.NET Core Controller Implementation

```csharp
[ApiController]
[Route("api/v1/subscriptions")]
public class SubscriptionsController : ControllerBase
{
    private readonly ISubscriptionService _service;

    public SubscriptionsController(ISubscriptionService service)
    {
        _service = service;
    }

    [HttpPost]
    [ProducesResponseType(StatusCodes.Status200OK)]
    [ProducesResponseType(StatusCodes.Status400BadRequest)]
    [ProducesResponseType(StatusCodes.Status500InternalServerError)]
    public async Task<ActionResult<SubscriptionResponse>> AddSubscription(
        [FromBody] CreateSubscriptionRequest request)
    {
        if (string.IsNullOrWhiteSpace(request?.Url))
        {
            return BadRequest(new ErrorResponse
            {
                Error = "Invalid request",
                Message = "URL is required and must not be empty"
            });
        }

        try
        {
            var subscription = await _service.AddSubscriptionAsync(request.Url.Trim());
            return Ok(new SubscriptionResponse
            {
                Id = subscription.Id,
                Url = subscription.Url,
                AddedAt = subscription.AddedAt
            });
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Error adding subscription");
            return StatusCode(
                StatusCodes.Status500InternalServerError,
                new ErrorResponse
                {
                    Error = "Internal server error",
                    Message = "An unexpected error occurred while adding the subscription"
                });
        }
    }
}
```
